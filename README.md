# 🍽️ My Food

A responsive food menu web application built using **HTML**, **CSS (Bootstrap)**, and **JavaScript**.  
It fetches and displays food recipes based on selected categories using the [Forkify API](https://forkify-api.herokuapp.com/).

---

## 🚀 Features

- ✅ Sticky Bootstrap 5 navbar
- ✅ Dynamic loading of food items via API
- ✅ Animated custom loader during fetch
- ✅ Responsive grid layout
- ✅ Error handling for failed requests

---

## 📸 Demo

Click on a food category (e.g., Pizza, Salad) to fetch recipes from the API. Recipes will be displayed as cards showing images, titles, and publishers.

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3** with [Bootstrap 5](https://getbootstrap.com)
- **JavaScript (Vanilla)**
- **Forkify API**

---

## ⚙️ How It Works

1. The navbar contains clickable food categories: `Pizza`, `Salad`, `Beef`, `Pasta`.
2. When clicked, the app fetches recipes using the Forkify API.
3. A custom animated loader is shown while fetching.
4. Results are displayed in a responsive Bootstrap grid layout.
5. If an error occurs, an error message is shown.
